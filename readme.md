# Rational
Класс для работы с рациональными числами, т.е. числами, которые можно представить в виде обыкновенной дроби, в которой числитель и знаменатель — целые числа. Примеры чисел: `1/2`, `3/4`, `-5/2`.

&nbsp;

Класс позволяет создавать объекты обыкновенных дробей с заданными числителем и знаменателем или же со значением по умолчанию (`0`/`1`).

При попытке создания дроби с нулевым знаменателем генерируется исключение `ArithmeticException("division by zero !")`.

Если дробь отрицательна, минус стоит перед числителем.

При создании дроби она сокращается, если такая возможность есть. Например, дробь `5/10` сократится до `1/2`.

&nbsp;

Также класс предоставляет возможность проводить с обыкновенными дробями

- элементарные операции: сложение, вычитание, умножение, деление.

- сравнения: на равно, на меньше, на меньше или равно.

При попытке деления на ноль генерируется исключение `ArithmeticException("division by zero !")`.

## Тесты

Ниже перечислены тестовые классы и содержащиеся в них методы с кратким описанием того, что они проверяют.

### ConstructorTests

- `testStandardConstructor` — проверяет конструктор без параметров, создает дробь 0/1.
- `testParametrizedConstructor` — проверяет конструктор с числителем и знаменателем.
- `testZeroDenominatorConstructor` — проверяет, что при знаменателе 0 выбрасывается исключение `ArithmeticException`.
- `testReduction` — проверяет сокращение дроби (например, 10/20 становится 1/2).
- `testNegativeReduction` — проверяет сокращение дроби с двумя отрицательными числами (например, -3/-9 становится 1/3).
- `testNegativeNumeratorReduction` — проверяет, что минус при отрицательном знаменателе переносится в числитель (3/-9 становится -1/3).
- `testCreationWithZeroNumeratorNegativeDenominator` — проверяет, что дробь с нулем в числителе и отрицательным знаменателем создается как 0/1.

### ArithmeticTests

- `testAddition` — проверяет сложение двух дробей.
- `testSubtraction` — проверяет вычитание двух дробей.
- `testMultiplication` — проверяет умножение двух дробей.
- `testDivision` — проверяет деление дробей.
- `testDivisionByZero` — проверяет, что при делении на дробь 0/1 выбрасывается исключение `ArithmeticException`.
- `testAdditionWithNegative` — проверяет сложение с отрицательной дробью.

### ComparisonTests

- `testEquality` — проверяет сравнение на равенство двух дробей.
- `testInequality` — проверяет, что разные дроби не равны.
- `testLess` — проверяет операцию "меньше".
- `testLessOrEqual` — проверяет операцию "меньше или равно".
- `testEqualsWithNull` — проверяет, что объект не равен null.

### SetterTests

- `testSetNumerator` — проверяет корректную установку числителя.
- `testSetDenominator` — проверяет корректную установку знаменателя.
- `testSetZeroDenominator` — проверяет, что установка нулевого знаменателя выбрасывает исключение.

### ToStringTests

- `testToStringPositive` — проверяет строковое представление положительной дроби.
- `testToStringNegative` — проверяет строковое представление отрицательной дроби.
- `testToStringZero` — проверяет строковое представление дроби с нулевым числителем.
- `testToStringReduction` — проверяет, что дробь корректно сокращается в строковом представлении.
